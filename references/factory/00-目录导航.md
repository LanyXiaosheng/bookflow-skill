# 从0到1AI写小说：目录导航

## 目录定位

这个目录现在的核心目标，统一收束为：

`主攻番茄短篇，做可批量复制的疯题项目工厂。`

不是继续泛泛收集资料，而是：

`赛道固定 -> 疯题筛选 -> 资产复用 -> 批量立项 -> 爆点控节奏 -> 试读优化 -> 发布复盘`

---

## 当前主生产桶

以后新增题目、资产、项目，优先归到这 4 个桶里：

1. `古言重生打脸`
2. `古言替嫁冲喜`
3. `现言婚恋火葬场`
4. `悬疑规则怪谈 / 疯批反转`

原则：

- 先把这 4 个桶打穿
- 不继续无边扩题材
- 每个新项目必须先判断自己属于哪个桶

## 现在的生产顺序

以后固定按这个顺序推进：

1. 先在疯题池看题
2. 先打分，再决定要不要立项
3. 立项后先补项目骨架，不急着全写正文
4. 每个项目必须补齐：
   - `00-项目说明.md`
   - `02-大纲.md`
   - `03-10章细纲.md`
   - `04-爆点节奏表.md`
   - `07-标题简介AB版.md`
5. 再进入：
   - `01-正文.md`
   - `08-前30%试读优化.md`
   - `09-前30%精修版.md`
   - `10-平台发布完整稿.md`
   - `12-分章节发布版.md`
6. 发布后一定回写复盘
