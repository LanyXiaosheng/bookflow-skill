# 番茄短篇人物关系模板

## 使用原则

短篇的人物关系不要太散。

最好围绕：

1. 女主
2. 男主
3. 核心恶人 1
4. 核心恶人 2
5. 关键推动角色

也就是 5 人核心盘，足够撑起一篇番茄短篇。

---

## 模板 1：女主 + 冷面男主 + 前任 + 白月光

### 适合题材

- 退婚打脸
- 改嫁死对头
- 前任后悔流

### 人物关系

- 女主：前世恋爱脑，今生清醒打脸
- 男主：前任死对头 / 权臣 / 皇叔 /冷面上位者
- 前任：势利、自私、爱惜羽毛
- 白月光：表面柔弱，实则心机深
- 家族长辈：谁得势就偏向谁

### 情绪效果

- 前任后悔
- 女主反杀
- 男主上位

---

## 模板 2：女主 + 病弱男主 + 恶毒娘家

### 适合题材

- 替嫁
- 冲喜
- 病弱王爷 / 世子
- 先婚后爱

### 人物关系

- 女主：被家族推出去送死
- 男主：表面病弱、实则藏锋
- 嫡姐 / 庶妹：不肯嫁，逼女主替嫁
- 继母 / 主母：用女主换利益
- 王府内鬼：制造后续生死危机

### 情绪效果

- 女主从弃子变王妃
- 娘家后悔
- 夫妻联手反杀

---

## 模板 3：女主 + 隐忍夫君 + 挑拨长姐

### 适合题材

- 和离
- 追妻火葬场
- 死后知真相

### 人物关系

- 女主：高自尊，误会后心死
- 男主：会做不会说，习惯隐忍
- 长姐 / 闺蜜型恶人：表面关心，实则挑拨
- 婆家长辈：加深误会与压力
- 外部政敌 / 家中钉子：推动悲剧升级

### 情绪效果

- 前世错过
- 今生追妻
- 误会拆开后高情绪兑现

## 模板 4：女主 + 世子男主 + 全员恶人侯府

### 适合题材

- 穿书
- 嫡女复仇
- 献祭冲喜
- 满门清算

### 人物关系

- 女主：穿书/觉醒后不再忍
- 男主：病弱世子 / 表面将死、实则清醒
- 侯爷父亲：卖女求荣
- 继母：主导害人计划
- 庶妹 / 弟弟：踩着女主换前程

### 情绪效果

- 全家压她
- 她掀桌
- 男主借势护她
- 全家被清算

## 模板 5：女主 + 查案男主 + 继母内鬼

### 适合题材

- 抄家前夜
- 家族旧案
- 内鬼递刀
- 改命保家

### 人物关系

- 女主：重生归来，知道灭门真相
- 男主：查案官员 / 权臣 / 都察使
- 继母：真正内鬼
- 父亲：糊涂偏信，给恶人机会
- 忠仆 / 弟妹：可救可弃的情感抉择点

### 情绪效果

- 倒计时破局
- 家中抓鬼
- 先清内宅，再翻外案

---

## 模板 6：女主 + 男主联盟 + 双反派夹击

### 适合题材

- 强剧情短篇
- 宅斗 + 权谋
- 双线清算

### 人物关系

- 女主：负责情绪线、内宅线
- 男主：负责外部权势线
- 反派 A：家中恶人
- 反派 B：外部势力
- 关键证人：中段翻盘点

### 情绪效果

- 内外双压
- 男女主从互相利用到同盟
- 结尾双线清算

---

## 人物关系搭建口诀

写短篇时优先套这个：

`女主受压 -> 男主有用 -> 恶人作恶 -> 证人翻盘 -> 结尾清算`

## 人物禁忌

不要：

- 人物太多
- 每个人都讲完整背景
- 配角功能重复
- 恶人太弱，压不住女主
- 男主太晚进场

## 一句话标准

人物关系好不好，看一条：

`每个人都得对女主的命运有推动作用。`
