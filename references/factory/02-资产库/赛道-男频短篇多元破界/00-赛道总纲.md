# 赛道总纲｜男频短篇多元破界

## 赛道定位

这是当前工作区的新增扩展赛道，用来避免全押女频。

重点不是古言情绪，而是：

- 高概念
- 逆袭
- 规则感
- 反转
- 男主视角爽点

## 核心关键词

- 逆袭
- 规则怪谈
- 都市脑洞
- 历史翻盘
- 末世
- 玄幻短爽文
- 悬疑反转
- 男主成长

## 为什么做这个赛道

1. 平台有男频短篇激励方向
2. 可扩大题材池
3. 防止工作区内容过窄
4. 适合测试另一类读者偏好

## 适合的核心题型

- 规则怪谈类短篇
- 都市逆袭类短篇
- 历史小人物翻盘
- 末世/灾变高概念短篇

## 当前阶段建议

- 题材池已经建立，可直接进入试跑立项
- 优先从 `规则怪谈 / 历史翻盘 / 末世灾变 / 都市脑洞` 中各做样板
- 先把男频项目清单与首批项目跑起来，再补发布链路

## 资产建设重点

- 男频标题模板
- 高概念开头模板
- 男主单线成长结构
- 规则/反转结尾模板
