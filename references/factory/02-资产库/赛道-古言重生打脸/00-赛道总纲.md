# 赛道总纲｜古言重生打脸

## 赛道定位

这是当前工作区最成熟、最适合持续批量化生产的主赛道。

核心关键词：

- 古代言情
- 重生
- 退婚
- 宅斗
- 嫡庶
- 改命
- 打脸
- 追悔莫及

## 为什么做这个赛道

1. 你当前项目积累最多
2. 开头强、冲突清楚、转化快
3. 最适合短篇快节奏推进
4. 可直接复用现有模板体系

## 适合的核心题型

- 重生大婚夜反杀
- 被退婚后高嫁
- 嫡庶婚嫁反转
- 抄家前夜改命
- 死后知真相再重来

## 标准结构

- 开头：屈辱现场 / 死亡回魂 / 大婚变局
- 中段：女主断关系 + 第一次反打 + 反派加码
- 后段：真相揭开 + 前任后悔 + 身份逆转
- 结尾：打脸兑现 + 命运逆转

## 适合的项目方向

- `重回被退婚当日，我改嫁死对头`
- `我死后才知夫君爱我，重生后我先和离`
- `重生回抄家前夜，我先送继母进牢`

## 资产建设重点

- 开头钩子模板
- 打脸反击台词模板
- 退婚/和离/宅斗标题模板
- 前任后悔结局模板
