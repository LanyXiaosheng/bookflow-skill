# 赛道总纲｜古言替嫁冲喜

## 赛道定位

这是古言里的高稳定情绪赛道，重点不是“前任后悔”，而是：

- 替嫁入死局
- 王府/侯府权势压迫
- 病弱男主藏锋
- 先婚后爱联手翻盘

## 核心关键词

- 替嫁
- 冲喜
- 病弱王爷
- 残王
- 世子
- 王府内鬼
- 夫妻联手
- 身份逆袭

## 为什么做这个赛道

1. 天然适合高冲突开头
2. 情绪盘和古言重生不同，能拉开题型差异
3. 更容易做“先婚后爱 + 权势感”
4. 很适合后续升级成中篇或短剧感题材

## 适合的核心题型

- 替嫁残王后改命
- 替庶妹嫁病弱王爷
- 冲喜世子实则藏锋
- 王府死局中夫妻反杀

## 标准结构

- 开头：被家族推出去替嫁
- 中段：王府危机 + 男主藏锋 + 女主站稳
- 后段：娘家后悔 + 内鬼暴露 + 夫妻联手
- 结尾：弃子变赢家

## 适合的项目方向

- `替嫁残王后，我靠预知改命`
- `替庶妹嫁给病弱王爷后，他竟夜夜装病`（待立项）

## 资产建设重点

- 替嫁标题模板
- 病弱男主人物盘
- 王府内鬼线模板
- 夫妻联手翻盘结局模板
