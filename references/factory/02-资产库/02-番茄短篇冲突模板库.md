# 番茄短篇冲突模板库

## 模板 1：大婚羞辱

- 场景：婚礼 / 大婚夜
- 冲突：庶妹、平妻、妾轿、换亲、退婚
- 用法：开头直接把女主推入最羞辱时刻

## 模板 2：重生回关键节点

- 场景：被害前、下狱前、退婚前、抄家前
- 冲突：女主知道未来，但身边人不知道
- 用法：适合快速建立“改命”驱动

## 模板 3：替嫁入局

- 场景：替嫁、冲喜、嫁病王、嫁残王
- 冲突：所有人都以为女主进的是死局
- 用法：方便做先抑后扬

## 模板 4：和离反杀

- 场景：和离书、休妻、另娶、纳妾
- 冲突：前夫轻贱女主，后期追悔莫及
- 用法：适合追妻火葬场

## 模板 5：宅斗夺位

- 场景：嫡庶、掌家权、嫁妆、继母陷害
- 冲突：女主必须在家族内部夺回位置
- 用法：适合中段持续制造压制与反打
