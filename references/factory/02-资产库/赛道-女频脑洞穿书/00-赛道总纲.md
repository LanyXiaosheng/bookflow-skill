# 赛道总纲｜女频脑洞穿书

## 赛道定位

这是高点击、高设定、高开局压迫感的试错赛道。

重点在：

- 穿书
- 觉醒
- 炮灰逆袭
- 系统/设定感
- 反手掀桌

## 核心关键词

- 穿书
- 炮灰嫡女
- 恶毒原配
- 献祭
- 觉醒
- 系统
- 改剧情
- 身份反转

## 为什么做这个赛道

1. 标题天然强钩子
2. 开头容易非常猛
3. 适合快速测试读者反应
4. 适合做高概念短篇

## 适合的核心题型

- 穿成被献祭的嫡女
- 穿成恶毒原配我不走剧情了
- 穿成冲喜炮灰后我反手上位
- 觉醒后我先送全家下狱

## 标准结构

- 开头：穿来就是马上要死
- 中段：掀桌 + 借势 + 反派破防
- 结尾：身份翻盘 + 恶人现世报

## 适合的项目方向

- `穿成被献祭的嫡女，我反手送全家下狱`
