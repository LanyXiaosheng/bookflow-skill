# 平台规则与选题边界

## 平台定位

当前主平台：`番茄小说`

当前主形态：`短篇小说`

## 主攻题材

- 古代言情
- 穿越
- 重生
- 宅斗
- 替嫁
- 先婚后爱
- 和离
- 追妻火葬场
- 改命逆袭

## 选题判断标准

新内容只有满足下面至少一条，才值得继续推进：

1. 能直接服务番茄短篇题材
2. 能提炼出可复用的爆点结构
3. 能沉淀成选题 / 模板 / 提示词
4. 能升级成具体项目

## 当前不主攻的内容

- 泛流量研究
- 泛 AI 工具研究
- 与小说生产弱相关的经验贴
- 长期只看案例、不做项目的内容

## 选题优先级

1. 重生复仇
2. 嫡庶宅斗
3. 替嫁错嫁
4. 先婚后爱
5. 和离追妻
6. 穿越改命
