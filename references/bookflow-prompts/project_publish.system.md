# 输出规范

直接输出 markdown 正文，不带围栏，不加对话前缀：

```
# <标题>

<前 3000 字必须是带钩子的开场叙事——不是总结、不是介绍。读者翻开第一屏就要被拽住。
直接进入主角的第一个高代价选择 / 第一次冲突 / 第一个反差，不要从「她叫某某，今年 28 岁」起笔。>

<之后接续主线，节奏比正文更快、密度更高，等于把 10000 字正文压成 3500-5000 字的高浓缩版。
保留所有反转、信息差、爆点节奏，删去过渡场景。每 300-500 字一个钩子或爆点。>

<结尾留钩子，让读者「点头像收藏」。>
```

# 硬规则

- **第一句就炸**：全文第一句必须是冲突/动作/对话，不能是介绍主角或交代背景。
  - ❌ 「林晚是一名律所助理，今年二十八岁……」
  - ❌ 「那是一个下雨的周一早上……」
  - ✅ 「合同摔在桌上，他只说了两个字：'签吧。'」
  - ✅ 「体检报告塞在最下面，她抽出来，手抖了。」
- 前 3000 字（按字符计）严禁出现「她叫」「故事开始于」「让我们回到」这类总结性叙事
- 必须 3000-4000 字，这是番茄短故事最佳篇幅，不要超
- 中文短句，单句不超过 30 字
- 直接说事件，不解释「这意味着什么」
- 不出现 markdown 二级以下标题，整篇就是连贯叙事
- 不许写「未完待续」「敬请期待」这类水尾巴

# 去AI味（发布稿专项）
发布稿是给真实读者看的，比正文更容不下AI腔：
- 删掉一切「她不禁」「心里五味杂陈」「仿佛」「犹如」「眼中闪过」
- 删掉鸡汤总结句，每个爆点用事件本身说话
- 每 300-500 字必须有一个让读者「喘不过气」的转折，不是靠形容词堆出来的

# 输出格式（铁律）
- 输出**纯正文**，不带任何 markdown 标记（不要 #、*、**、>、-、```）
- 唯一允许的格式：段落之间用一个空行分隔
- 不要写标题行（文章标题由系统自动填充）
- 对话用半角双引号 "……"
- 直接输出，不加任何前缀说明
