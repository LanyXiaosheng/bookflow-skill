# 读者视角的硬标准
- **首句即冲突**：每章第一句就扔钩子，不让读者等
- **第一人称代入感**：严格保持主视角，「我」的感知、情绪、动作贯穿全文，不要跳出
- **对话驱动**：把平淡叙述改成对话，两个人说话比一个人想有张力
- **短句+空行**：每段 1-3 句，超 60 字必拆，段间空行，读起来透气
- **不贪多**：一个动作一句话就说清，不要拆成三步还加比喻。写「她脚步很乱」就够了，不用写「不像平日稳当，倒像被猫追」

# 不改的底线
1. 不改剧情事实、人物关系、结局走向
2. 不改角色名、称呼、背景设定
3. 字数不膨胀（篇幅与原稿大致相当）
4. 不新增设定、不补情节

# 去 AI 味（逐句审查，这是最重要的步骤）

**第一轮：删词**
扫描全文，以下词/句型直接删掉或改写：
- 「她不禁」「他忍不住」「心里五味杂陈」「莫名」「某种情绪」「油然而生」
- 「仿佛」「犹如」「好像」「宛如」开头的比喻（保留比喻，去掉这些引导词）
- 「眼中闪过」「眸子里」「深邃」「清澈」等眼神描写套路
- 「这一切」「这一刻」「这种感觉」「此刻」等抽象概括词
- 「然而」「尽管如此」「与此同时」「不仅如此」开头的转折句
- 反问铺垫：「她怎么会……」「谁能想到……」「哪知道……」
- 鸡汤金句式段尾：「有些人，注定只是过客」「爱，是最沉重的枷锁」类

**第二轮：破结构**
检查每一章开头——如果是背景交代，改成动作/对话/冲突。
检查章节节奏——如果每章都是「起承转合」，故意在某章中间插一个意外打断节奏。

**第三轮：句子活化**
- 把「她感到害怕」改成她的具体动作（手抖了、往后退了半步）
- 把「他很生气」改成他做了什么（他把杯子放下，声音压得很低）
- 删连续3个以上的并列结构，保留最有力的一个

- 删掉空泛铺垫、套话、强调性副词
- 用主动表达，不让抽象事物承担动作
- 句长有变化，段尾不总用金句式收尾
- 禁用 em dash（—），不写可摘抄的 AI 腔句子
