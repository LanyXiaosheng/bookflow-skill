# 去AI味共享规则（所有写作步骤强制执行）

## 硬禁词表（出现即删，无例外）

### 心理描写套路
她不禁、他忍不住、心里五味杂陈、莫名、某种情绪、油然而生、内心深处、暗暗想到、心中一动、不由得

### 比喻引导词
仿佛、犹如、好像、宛如、恰似、如同

### 眼神描写套路
眼中闪过、眸子里、深邃、清澈、眼底划过、目光如炬、眼神复杂

### 抽象概括词
这一切、这一刻、这种感觉、此刻、那一瞬间、在这个时候

### 转折套话
然而、尽管如此、与此同时、不仅如此、除此之外、话虽如此、不过话说回来

### 反问铺垫
她怎么会……、谁能想到……、哪知道……、难道……不成？、何曾想过

### 鸡汤金句（段尾绝对不能用）
有些人注定只是过客、爱是最沉重的枷锁、命运从不会亏待努力的人、一切都是最好的安排、生活总会给你答案

### 过度修饰
极其、无比、格外、异常、十分、非常（连续使用2个以上时删掉）

### 结构性AI腔
em dash（—）作为插入语、连续3个并列排比、二元对照句式（不是X而是Y）、先否定再肯定的假转折

## 句子检测规则

1. **同一段里出现2个以上形容词** → 只保留最具体的那个，删掉其余
2. **段尾是金句/感悟式收尾** → 改成动作或对话
3. **连续2句以上主语相同** → 变换句式或合并
4. **"他/她+心理动词"出现超过2次** → 换成肢体动作表达
5. **段落全是叙述没有对话** → 至少插入一句话或一个声音

## 替代方案速查

| 禁用 | 替代 |
|------|------|
| 她不禁感到害怕 | 她往后退了半步 |
| 他心里五味杂陈 | 他把烟掐灭，又点了一根 |
| 眼中闪过一丝xxx | 她没说话（用沉默代替） |
| 仿佛整个世界都安静了 | 删掉，直接写下一个动作 |
| 这一刻她终于明白了 | 删掉，读者自己会懂 |
| 然而事情并没有这么简单 | 直接写发生了什么 |

## 节奏检测

- 如果连续3段都是"短句短句短句"→ 中间插一个稍长的句子（但不超60字）
- 如果连续3段都是"叙述叙述叙述"→ 必须插入对话
- 如果每章开头都是动作 → 偶尔用一句对话开头
- 如果每章结尾都是悬念 → 偶尔用一个安静的画面结尾（打破读者预期）
